# Préparation de la soutenance

Le sujet prévoit 15 minutes de présentation/démonstration, puis 3 minutes de questions. Tous les membres interviennent.

## Déroulé proposé

1. Architecture et flux réseau.
2. Démarrage local et reproductibilité.
3. Comparaison local / VM Énov.
4. Démonstration SSO Authentik → Rallly.
5. Démonstration des droits par groupe.
6. Démonstration de l'invitation externe.
7. Preuve de pipeline CI/CD verte.
8. Démonstration des fonctionnalités.
9. Mesures de sécurité, limites connues et pistes d'amélioration.

## Vérifications avant le jour J

- [ ] Dépôt public et README testés depuis un clone propre.
- [ ] VM accessible au formateur.
- [ ] Comptes de démonstration opérationnels.
- [ ] E-mail d'invitation testable.
- [ ] Pipeline verte sur `main`.
- [ ] Captures de secours disponibles.
- [ ] Répartition de parole répétée et chronométrée.
- [ ] Aucun secret visible dans les captures ou l'historique Git.
